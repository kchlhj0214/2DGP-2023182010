# Drill #8 애니메이션 뷰어

`character_runs.py`의 pico2d 캔버스 열기 → 이미지 로드 → 반복 재생 → 캔버스 닫기 구조를 바탕으로 구현했습니다.

## 구현 목표

- 최소 네 종류의 애니메이션을 화면 중앙에서 확대 재생
- 각 동작을 다섯 번 재생하고 마지막 프레임에서 1초 정지
- 모든 동작을 순서대로 무한 반복
- 프레임마다 다른 잘라내기 크기와 동작마다 다른 프레임 수 지원

모든 과제 파일은 이 폴더 안에 보관합니다.

## 실행

저장소 최상위에서 PowerShell로 실행합니다.

```powershell
.\.venv\Scripts\python.exe LEC08\animation_viewer.py
```

일반 Python 환경에서는 `python -m pip install pico2d==1.5.1`로 설치한 뒤
`python animation_viewer.py`를 이 폴더에서 실행합니다. 리소스 경로는 소스 파일 위치를 기준으로 찾으므로 작업 디렉터리가 달라도 실행됩니다.
뷰어 실행에는 Pillow가 필요하지 않습니다.

## 재생 및 조작

| 순서 | 동작 | 프레임 수 | 초당 프레임 |
| --- | --- | --- | --- |
| 1 | 대기 (IDLE) | 2 | 4 |
| 2 | 달리기 (RUN) | 8 | 10 |
| 3 | 점프 자세 (JUMP) | 4 | 6 |
| 4 | 검 공격 (ATTACK) | 5 | 9 |

각 동작은 마지막 프레임의 표시 시간까지 포함해 정확히 5회 재생한 후 마지막 자세로 1초 정지합니다.
공격이 끝나면 다시 대기부터 반복합니다. 점프도 위치를 이동시키지 않고 중앙에서 자세를 재생합니다.
글자나 장식 없이 기본 캔버스에 캐릭터만 표시합니다. 800×600 창에서 7배로 확대하여 모든 프레임의 높이가 화면 높이의 절반 이상입니다.

- `Esc` 또는 창 닫기: 종료
- `R`: 대기 동작부터 다시 시작

## 가산점 구현 설명 (제출용)

프레임별로 서로 다른 `(x, y, 너비, 높이)`를 저장한 비정형 스프라이트 시트를 사용하고, 투명 여백 제거 전의 오프셋과 발 기준점을 보정해 흔들림 없이 재생했습니다.
애니메이션마다 독립적인 프레임 목록(대기 2·달리기 8·점프 4·공격 5)을 사용하여 프레임 수가 달라도 각각 5회 반복 후 1초 정지하도록 구현했습니다.

## 파일과 스프라이트 처리

- `animation_viewer.py`: 기본 캔버스, 캐릭터 확대 표시, 키 입력
- `animation_data.py`: 프레임 정보 로딩과 검증
- `playback.py`: 시간 기반 프레임 전환, 반복, 정지, 순환
- `assets/swordsman.png`, `assets/swordsman.json`: 비정형 시트와 프레임 좌표
- `assets/source/`: 변경 전 원본 이미지 네 장
- `assets/CREDITS.md`: tbbk의 Hero Swordsman 원본 링크 및 CC0 라이선스
- `build_atlas.py`: 원본 투명 여백 제거 및 시트 재생성

소닉 예제에서 보이는 동작별 프레임 수와 프레임 크기 차이를 구현 대상으로 삼았습니다.
선택한 원본은 주로 64px 칸을 사용하므로, 실제 불투명 영역만 잘라 크기가 다른 프레임으로 재배치했습니다.
특히 공격 두 번째 프레임은 칼 이펙트가 64px 칸 밖으로 넘어가므로 80px 영역을 읽어 실제 70×54px 그림을 보존합니다.
픽셀 아트 자체를 새로 그리거나 변형하지 않았습니다.

## 검증과 재생성

개발용 도구에만 Pillow가 필요합니다. 아래 명령은 저장소 최상위에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install Pillow
.\.venv\Scripts\python.exe -m unittest discover -s LEC08 -p "test_*.py" -v
.\.venv\Scripts\python.exe LEC08\verify_render.py
.\.venv\Scripts\python.exe LEC08\build_atlas.py
```

- 자동 테스트 9개: 정확한 5회 재생, 마지막 프레임 시간, 1초 정지, 여러 순환의 시간 보존, 원본 픽셀 보존, 확대 크기, 시트/화면 경계, 잘못된 데이터 검사
- 실제 pico2d/SDL로 19개 프레임과 정지 화면 렌더링, R/Esc/창 닫기 검증
- `_preview/`는 검토용 화면과 임시 자료이며 Git에서 제외합니다.

Python 3.13.15 / pico2d 1.5.1 / Windows 환경에서 검증했습니다.
