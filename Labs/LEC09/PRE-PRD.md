소닉 애니메이션 뷰어 작성

개발언어 python
라이브러리 pico2d
파일이름 sonic_animation_viewer.py
단일 파일로만 작성.
스프라이트 이미지 sonic-sprite.png


기능
이미지의 모든 동작을 재생
동작별 5회 재생, 1초 쉬고, 그 다음 동작 재생
모든 동작을 다 재생한 후, 다시 무한 반복

이동 기능
걷기, 달리기, 회전, 회전 공, 빠른 달리기, 전력 질주는 자동으로 좌우 이동
걷기보다 달리기가 빠르게 보이도록 동작별 이동 속도를 다르게 적용
제동 동작은 이동 속도를 점차 줄여서 정지
화면 끝에서는 캐릭터가 잘리지 않도록 방향을 바꾸고 이미지를 좌우 반전
동작별 5회 재생 후 1초 쉬는 동안에는 프레임과 위치, 방향을 모두 유지
다음 동작으로 넘어갈 때 위치와 방향을 이어서 사용
이동이 없는 포즈는 현재 위치에서 재생하며, 키보드 이동 조작은 추가하지 않음

기본 윈도우 크기 1600×800
화면 대비, 이미지가 잘 보이게 충분히 확대

개발 방법:
한번에 다 개발하지 말고, 단계별로 구현해서, 커밋을 그때 그때 할 수 있도록
최소한 개발단계는 20단계 이상으로 할 것
